# Results

We evaluate the LAMNr framework by characterizing its ability to linearize
complex anatomical manifolds across two data modalities: (1) high-dimensional
tabular phenotypes using RealNVP architectures, and (2) multi-modal MRI using
multiscale Glow networks. Tabular experiments allow for the efficient and
computationally tractable evaluation of alignment strategies (e.g., VICReg, 
HSIC), which we can then leverage to demonstrate the utility of LAMNr flows
for providing a principled, likelihood-based foundation for exploring different
aspects of the proposed Glow-based, Deep Computational Anatomy LAMNr framework.
